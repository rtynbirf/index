# ЯВКА ДОМА · карточки деятелей (Ф-Я · волна-19)

Ввод 16.11.2026 по мандату Хозяина (ключ №6 вручную), трек Т2 из
«Рекогносцировки мировых практик и эмерджентного синтеза» (волна-18).

Мировая опора: **Agent Card** протокола A2A — публичная карточка
возможностей для discovery. Канон дома: признание агента (п. 117 журнала
свода), глава VIII — карточка объявляет **границы**, а не права; ст. 21 —
носитель не несёт права.

## Форма карточки

JSON-файл в этой папке. Поля:

| Поле | Смысл |
|------|-------|
| `name` | имя деятеля |
| `kind` | человек / агент / механизм |
| `capabilities` | что умеет |
| `boundaries` | чем ограничен (границы, не права) |
| `verification` | чем проверяется (детерминированные пробы) |
| `mandate` | текущий мандат |
| `death_date` | срок смерти полномочия по Ф-III-7 |

реестра репо (описание репо живёт в `projects.json`, описание деятелей —
здесь).
