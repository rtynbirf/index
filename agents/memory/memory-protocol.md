## Правила гигиены (из мировых практик, с «как проверено»)

1. Верхний слой мал: ≤ 200 строк; длина снижает adherence (Anthropic, 06.11.2026). Проверено: волна-20, слой ~60 строк.
2. Писать «для чего память», не «как её использовать»; жёсткие правила «писать только провалы» снижают выигрыш (там же). Проверено: протокол задаёт назначение, не микрорежим.
3. Хранить то, что нельзя перечитать каждый ход: стратегии, планы, проверенные правила — не видимый экран (там же). Проверено: карта района, долги, правила-ломатели.
4. Параллельным писателям — отдельные страницы (там же, против перезаписей). Проверено: pages/stazh.md отделён; сосед-агент ведёт ATP и ЛЕТОПИСЬ в хабе.
5. Память — предсказание: записанное правило — ставка, что пригодится; хранить способ проверки (там же). Проверено: каждое правило в MEMORY.md имеет поле «Проверено».
6. Заметку против лога: dream-сверка исправляет неверно записанный факт (пример «Mt Moon DONE» из статьи). Проверено: FSM СВЕРКА отвергла переход в волна-18, такт перестроен.

## Ритуал агента (минимум, без микрорежима)

Входя: прочти MEMORY.md (первое дело). Выходя: допиши свою страницу pages/<имя>.md с датой;
в верхний слой — только то, что сломает работу следующего такта (долги, новые правила, смена карты).
